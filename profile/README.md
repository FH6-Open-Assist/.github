# FH6 Open Assist

Automação aberta para reduzir tarefas repetitivas no **Forza Horizon 6**.

O projeto reúne três fluxos principais:

- **Skill Points**
- **CR Glitch**
- **WheelSpin Mad Mike**

## Começar

- [Acessar o código e a documentação](https://github.com/FH6-Open-Assist/FH6-Open-Assist)
- [Baixar a versão mais recente](https://github.com/FH6-Open-Assist/FH6-Open-Assist/releases/latest)
- [Relatar um problema](https://github.com/FH6-Open-Assist/FH6-Open-Assist/issues)

> Projeto independente e não oficial, sem vínculo com Microsoft, Xbox ou Playground Games. Use automações por sua conta e risco.
